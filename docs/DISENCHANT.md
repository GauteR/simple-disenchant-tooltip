# Simple Disenchant Tooltip — datakilde

Addonen viser disenchant-linjer i tooltips:

1. **Materiale** — de **to** beste farm-kildene (høyeste + nest høyeste sjanse; sammenslått ilvl per quality+type)
2. **Utstyr** — **alle** forventede DE-utfall (sortert etter sjanse)

Linjefarge etter drop-sjanse: **grønn** ≥ `CHANCE_GREEN` (75), **gul** ≥ `CHANCE_YELLOW` (35), ellers **grå**. Ingen %-tall i teksten.

## Scope

- Forever (`Interface: 16001`)
- Tabeller basert på **Vanilla Classic (1.12)** disenchant-data (`Data/Tables.lua`)
- Kun Vanilla-reagenser (Strange Dust → Nexus Crystal); ingen TBC+

## Oppførsel

- Material-hover: `Config.MATERIAL_SOURCES` (topp 2 sammenslåtte kilder)
- Gear-hover: `Config.ITEM_OUTCOMES` (alle outcomes; krever `GetItemInfo` / `C_Item.GetItemInfo`)
- Ilvl utenfor Vanilla-bånd: `Config.OUTCOME_LEVEL_FALLBACK` klamper til **nærmeste** band (f.eks. Rare under ilvl 16 → Small Glimmering; Uncommon over 65 → topp Illusion-band). Forever lavnivå-blues som Gemmed Copper Boots.
- Gear-priser: `Config.OUTCOME_PRICES` — under outcome-linjer (kun navn/antall, sjanssefarget): `AddDoubleLine` **Disenchant** (gul etikett, hvit myntverdi) med forventet AH-verdi for det **mest sannsynlige** utfallet. Enhetspris: **TSM** via global `TSM_API.GetCustomPriceValue(Config.TSM_PRICE_SOURCE, itemString)` (`DBMarket` default; itemString `ToItemString` / `i:<id>`) først, deretter Auctionator (`OptionalDeps: TradeSkillMaster, Auctionator`). Formel: `(sjanse/100) × snittantall × enhetspris`. MoneyFrame-ikoner (12×12, Auctionator-spacing: mellomrom etter ikon før neste tall); null-denominationer skjules; ledende null kun på valører under høyeste viste (`1c`, `1s 01c`, `1g 01s 01c`). Mangler pris på topp-utfallet → ingen Disenchant-linje. TSM på Forever er soft-dep (**Unverified** in-game).
- Master-flag: `Config.ENABLED`
- Shield / off-hand telles som **WEAPON** i DE-tabellene (essence-primær)
- Tooltip-hook: `TooltipDataProcessor` når tilgjengelig; ellers `OnTooltipSetItem` på GameTooltip, ItemRefTooltip, ShoppingTooltip1/2, EmbeddedItemTooltip
- Dedupe: `_SimpleDisenchantTooltipAppended` lagrer sist appendede `itemId` per tooltip-frame; `AppendForItem` hopper over re-entry for samme item (f.eks. Auctionator Vendor/Auction-refresh). Nullstilles på `OnTooltipCleared` / `OnHide` via `Tooltip:ClearAppendState`
- `ENABLED = false`: chat-melding ved login; ingen slash/tooltip/Options

## Observed level ranges

`Data/ObservedLevels.lua` (generated by `scripts/update_observed_levels.lua`; do not edit by hand). Source: [BootyBayBroker Forever DE odds](https://bootybaybroker.com/forever/crafting/disenchant) (client build 1.60.1.70755 brackets + observed/inferred results). Rows are material → quality → type → min/max **item level** (union of BBB bands). Rare/Epic use `ANY` (matches `Tables:BuildMaterialSources`). Flag: `Config.OBSERVED_LEVELS`.

**Update on demand.** BootyBayBroker returns 403 to scripts, so save the page from a browser (Save as → HTML) and run `./scripts/update-observed-levels.sh <page.html>` or `./scripts/update-observed-levels.ps1 <page.html>` (`--dry-run` / `-DryRun` previews band changes). When any band changed, `Config.VERSION` gets a patch bump (data-only release; `--no-bump` / `-NoBump` skips it). The script does not commit or tag; `release.sh` does. Saved pages under `scripts/.cache/` are gitignored.

Notable Forever vs Vanilla (from BBB): uncommon **weapons** ilvl 21–30 yield **Greater Magic Essence** (not Lesser/Greater Astral); top uncommon/rare bands extend to **ilvl 99**; Rare Small Glimmering starts at **ilvl 5**.
